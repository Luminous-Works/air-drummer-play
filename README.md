# Air Drummer (play build)

A hands-only, seated AR drum game for Meta Quest, built with the Immersive Web SDK.

This repository holds only the built website that GitHub Pages serves. Open the Pages link on a Quest
(or in a desktop browser with the Immersive Web Emulator) and press Enter XR.

Third-party: the Professor Beat Bop robot model is Meta's MIT-licensed stock asset
(see gltf/robot/LICENSE.txt).
